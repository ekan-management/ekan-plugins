# Ekan Plugins Marketplace

Marketplace för Ekans Claude Code-plugins. Lägg till i Claude Code:

```
/plugin marketplace add ekan-management/ekan-plugins
```

Sedan installera ett plugin:

```
/plugin install ekan@ekan-plugins
```

## Tillgängliga plugins

- **ekan** — Ekans AI-konsult-OS. Se [ekan-consulting-os](https://github.com/ekan-management/ekan-consulting-os).
